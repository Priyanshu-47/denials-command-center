# Meridian PPO - Coding Policy DX-EXCL-03 (applies to all network payers using ICD-10-CM edits)
## ICD-10-CM Excludes1 Edits

1. An Excludes1 note means the two conditions cannot be reported together.
2. Example enforced edit: I10 (Essential (primary) hypertension) Excludes1 hypertensive heart disease (I11.-). Claims reporting I10 together with any I11.- code will deny (CARC 11).
3. The corrected claim should report only the more specific code (I11.-).
4. Corrected claims must be received within 90 days of the denial.
